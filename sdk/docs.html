ShieldCaptcha Enterprise v4.0

ShieldCaptcha is an enterprise bot defense engine designed to verify legitimate human interaction while preventing automated scripts, scrapers, and credential stuffing.

Zero Dependencies: Operates entirely on standard Node.js or Python runtime primitives without external npm packages or native C/C++ compilation.

Dual-Defense Paradigm

Standard traffic receives frictionless 1-Click Proof-of-Work Turnstile verification. Suspicious or high-risk traffic is automatically escalated to an adversarial procedural jigsaw puzzle.

Quickstart Guide

Integrate ShieldCaptcha with any HTML form in 3 steps:

1. Include the client script

<script src="http://localhost:3000/captcha.js"></script>

2. Mount the widget container

<form id="login-form">
  <input type="email" id="email" required />
  <div id="captcha-box"></div>
  <button type="submit" id="btn" disabled>Sign In</button>
</form>

<script>
  let token = '';
  ShieldCaptcha.mount(document.getElementById('captcha-box'), {
    mode: 'checkbox',
    onToken: (t) => {
      token = t;
      document.getElementById('btn').disabled = false;
    }
  });
</script>

3. Verify token on backend

const res = await fetch('http://localhost:3000/api/siteverify', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Site-Secret': process.env.SITE_SECRET
  },
  body: JSON.stringify({ token: userToken })
});
const data = await res.json();
if (!data.success) throw new Error('Verification failed');

Node.js Engine Setup

The Node.js server runs standalone using native Node.js APIs (crypto, http, zlib):

cd backend-node
node server.js

Production PM2 Cluster

npm install -g pm2
pm2 start server.js -i max --name "shield-captcha"

Python FastAPI Setup

Asynchronous ASGI alternative powered by FastAPI and Uvicorn:

cd backend-python
pip install fastapi uvicorn pillow
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

JavaScript SDK API

const controller = ShieldCaptcha.mount(element, {
  mode: 'checkbox', // 'checkbox' | 'jigsaw' | 'adaptive'
  
  onToken: (token, meta) => {
    console.log('Verified token:', token);
    console.log('Trust score:', meta.score);
  },
  onReset: () => {
    console.log('Challenge reset');
  }
});

controller.switchMode('jigsaw'); // Switch mode on demand
controller.reset();              // Reset to fresh challenge

React & Next.js Integration

import { CaptchaWidget } from "@/components/CaptchaWidget";

export function AuthForm() {
  const [token, setToken] = useState("");

  return (
    <form>
      <input type="email" placeholder="Account email" />
      
      <CaptchaWidget
        mode="checkbox"
        onToken={(t) => setToken(t)}
        onReset={() => setToken("")}
      />

      <button type="submit" disabled={!token}>
        Sign In
      </button>
    </form>
  );
}

Server-Side Verification (/api/siteverify)

Verify the token with ShieldCaptcha before completing user login:

POST /api/siteverify
Headers:
  Content-Type: application/json
  X-Site-Secret: sec_your_site_secret

Body:
{
  "token": "YOUR_CAPTCHA_TOKEN"
}

Response (200 OK):
{
  "success": true,
  "trustScore": 95,
  "authMode": "checkbox_pow"
}

1-Click Proof-of-Work

Clients compute a SHA-256 hash with leading zero bits inside a Web Worker. Fast for legitimate users (< 20ms) while imposing computational throttling on automated scrapers.

Production Deployment

server {
    listen 443 ssl http2;
    server_name captcha.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /captcha.js {
        proxy_pass http://127.0.0.1:3000;
        expires 1h;
    }
}
